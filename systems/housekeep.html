MAIN FEATURES

受付から定期訪問・完了報告まで、
10の主要機能。

予約フォームだけではなく、事務所での割当、現場の確認、顧客への報告までを実際の運用につなげます。

LINE

LINE予約・見積り相談

専門清掃、家事代行、無料見積りから選び、サービス、訪問先、希望日時、要望を受け付けます。

30M

30分単位の希望時間

過去日時を選ばせず、営業日・空き状況に応じた30分単位の希望枠を表示します。

CRM

顧客・訪問先の再利用

登録済みのお客様は氏名、電話番号、訪問先を再取得し、次回予約の入力負担を減らします。

PC

オーナーPC総合管理

本日の訪問、予約、顧客、問い合わせ、担当、料金、支払状況、注意事項を一覧で確認します。

TEL

電話・店頭受付

LINEを利用しないお客様も、電話・店頭予約として同じ予約・訪問一覧へ登録できます。

REPEAT

定期契約・訪問予定生成

毎週・隔週・毎月の契約を管理し、今後の訪問予定をまとめて作成します。

STAFF

担当割当・重複確認

担当スタッフ、対応業務、勤務時間、1日上限を確認しながら案件を割り当てます。

FIELD

現場進捗・訪問情報

移動中、到着、作業中、お客様確認、完了を更新し、電話・地図・鍵・駐車場・注意事項を確認します。

CHECK

必須作業チェック

必須項目をすべて確認してから完了へ進むことで、作業漏れの確認を標準化します。

PHOTO

作業写真・公開範囲

作業前後、傷・破損、レシートなどを非公開領域へ保存し、作業前後写真だけをお客様へ公開できます。

FROM REQUEST TO REPORT

予約・相談から完了報告まで、
6つの流れ。

受付だけをデジタル化するのではなく、見積り、担当、訪問、チェック、写真、完了確認までをつなぎます。

01

LINEから予約・相談

お客様が利用種別、サービス、希望日時、訪問先、鍵・駐車場・ペット、ご要望を送信します。

02

内容・見積りを確認

事務所が予約内容を確認し、必要に応じて写真や訪問確認を経て見積り・日時を確定します。

03

担当スタッフを割当

対応業務、勤務情報、他案件との重複を確認し、担当スタッフを決定します。

04

訪問・作業を進行

現場スタッフが電話・地図・入室情報を確認し、移動、到着、作業開始を更新します。

05

チェック・写真を記録

必須チェック、現場メモ、作業前後写真、必要な内部写真を案件へ保存します。

06

完了・お客様確認

料金・支払状況・作業報告を整理し、お客様はマイページで完了状況と公開写真を確認できます。

BEFORE / AFTER

予約フォームを増やすだけでなく、
現場完了までをつなぐ。

電話を完全になくすのではなく、LINE受付・電話受付・現場連絡を同じ顧客・予約情報へまとめ、確認経路を整理します。

BEFORE

受付・予定・現場報告が、それぞれ別の方法。

  • 電話やLINEの内容を紙・表計算へ転記
  • 鍵・駐車場・注意事項を個別に連絡
  • 担当者の空きや重複を都度確認
  • 作業チェック・写真が担当者任せ
→
AFTER

受付から完了報告まで、同じ案件情報で確認。

  • LINE・電話受付を同じ予約一覧へ登録
  • 訪問条件を現場スタッフ画面へ共有
  • 担当・定期契約・訪問予定をPCで管理
  • 必須チェック・写真・進捗を案件へ記録

SAFE OPERATION

公開デモから本番導入まで、
安全確認を前提に。

公開デモは架空情報で構成し、本番は契約事業者ごとに環境を分離します。内部の営業前検査はDPRO SHOP側で行い、管理コードや接続情報は紹介ページへ掲載しません。

01 / SEPARATE

デモと本番を分離

公開デモは架空データ、本番は契約事業者専用のGitHub・Worker・データベースとして分離します。

02 / TENANT

事業者ごとの環境分離

事業者コードと専用環境を前提に、他事業者の顧客・予約・写真と混在させない構成で導入します。

03 / AUTH

管理・現場画面の認証

オーナー画面とスタッフ画面は管理用認証を前提とし、管理コードをURLや公式紹介ページへ埋め込みません。

04 / PRIVATE PHOTO

写真の公開範囲を分離

写真は非公開領域へ保存し、お客様へ公開できる対象を作業前・作業後写真に限定します。

05 / GUARD

本番保護・デモ準備ガード

営業用デモデータの準備は、デモ事業者かつ本番保護が有効な環境だけで実行する設計です。

06 / DPRO CHECK

公開前検査はDPRO SHOPが実施

Worker、データベース、保存先、認証、電話番号正規化、公開画面などを内部検査してから本番運用へ進みます。

FAQ

ハウスクリーニング・家事代行向けDPROシステムの
よくある質問。

どのくらいの規模の事業者に向いていま⁠す⁠か⁠。

少人数から複数スタッフで、単発清掃・家事代行・見積り・定期訪問を扱う事業者を想定しています。現在の受付方法、スタッフ数、対応エリア、サービス数を確認して導入範囲を決めます。

現場スタッフはスマートフォンだけで使えま⁠す⁠か⁠。

はい。現場スタッフ画面はスマートフォンとiPad・タブレットを想定し、担当案件、電話、地図、訪問条件、進捗、チェック、写真を確認・更新できます。

LINEを使わないお客様も管理で⁠き⁠ま⁠す⁠か⁠。

はい。オーナーPCから電話・店頭受付として登録し、LINE予約と同じ予約・訪問一覧で管理できます。お客様マイページは電話番号で確認する導線も用意されています。

今使っている電話・紙・表計算と併用で⁠き⁠ま⁠す⁠か⁠。

導入直後からすべてを置き換える必要はありません。まずLINE受付、担当割当、現場チェックなど必要な部分から併用し、運用に合わせて移行範囲を整理します。

公開デモに本物のお客様情報は入っていま⁠す⁠か⁠。

入りません。公開デモは架空データを使用します。本番環境は契約事業者ごとに分離し、公開デモとは別のGitHub・Worker・データベースで運用します。
