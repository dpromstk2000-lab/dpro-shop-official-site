WHY DPRO

単発の駆除ではなく、対応履歴まで管理する。

写真、現場メモ、報告書、次回予定が別々になると、継続管理ほど確認コストが増えます。DPROは案件を軸にEvidenceをつなぎます。

ISSUE 01

相談内容と現地調査が分断する

最初の写真やPDFを案件の入口にし、調査・施工の記録へつなげるため、受付から現場までの情報差を小さくします。

ISSUE 02

現場の根拠が担当者の端末に残る

Evidence Chain、薬剤・安全確認、Field Map / Trap PINなどを共通の案件情報として追えるようにします。

ISSUE 03

報告後の再訪・定期点検が切れる

報告で終わらず、再訪・保証・次回点検まで同じ案件の流れとして確認できる設計です。

CORE FUNCTIONS

環境衛生の「証跡」と「次の対応」を中心に設計。

WEB・LINE相談写真や要望を案件の入口にして受付情報を整理。
写真・PDF Evidence相談資料・現場資料を案件単位で扱う。
現地調査・施工記録調査内容、施工、薬剤、安全確認を追跡。
Field Map / Trap PIN現場内の確認ポイントや設置位置を扱う専用導線。
公開報告Customerへ見せる情報と内部記録を役割で整理。
再訪・保証・定期点検一度の対応で終わらず、次回アクションへつなぐ。
FIELD EVIDENCE

「現場で見たもの」を、報告書だけに閉じ込めない。

現場情報は、後日の問い合わせや定期点検で再利用できることが重要です。

Evidence Chainで残す

  • 相談時の写真・PDF
  • 調査時の確認内容
  • 施工・薬剤・安全確認
  • 現場位置・Trap PIN
  • 報告・再訪の経緯

次回の判断につなげる

  • 前回の対応内容を確認
  • 同じポイントの変化を追跡
  • 保証・再訪の判断材料を共有
  • 定期点検のNext Actionを確認
  • 担当変更時も案件履歴を参照

FAQ

導入前によく確認されること。

単発の害虫・害獣対応にも使えますか？

はい。単発相談でも、相談内容・現地調査・施工・報告までを一つの案件として追える構成です。定期管理では、その後の再訪・点検までつなげられます。

飲食店や管理物件の定期防除にも向いていますか？

Evidence Chain、Field Map / Trap PIN、再訪・定期点検など、継続して現場履歴を追うための導線を用意しています。実際の運用方法は導入時に確認します。

Tutorialが勝手にデモデータを書き換えることはありますか？

受入済みTutorial V1.2.2は実画面の対象確認を目的とし、相談送信、保存、Field Map / Trap PIN保存、Demo Prepareなどのbusiness mutationを自動実行しない安全境界です。

契約前に本番用のOwnerや顧客データを作りますか？

作りません。標準製品と公開デモの確認後、契約後の別工程でTenant、Owner/Auth、本番設定を行います。
