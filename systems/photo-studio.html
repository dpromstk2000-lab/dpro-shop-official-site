MAIN FEATURES

撮影前から納品後までを支える、
10の主要機能。

「予約を受ける」だけで終わらず、撮影対象者の情報、当日の現場、写真選び、制作・納品、次の注文までを実際の運用につなげます。

LINE

撮影プラン・空き枠予約

プラン、オプション、担当者を選び、30分単位の空き時間からスマートフォンで予約します。

SUBJ

撮影対象者管理

人物、子ども、乳幼児、ペット、商品、家族・団体など、撮影する対象を予約へ登録します。

ASK

事前ヒアリング

撮影目的、希望する雰囲気、希望カット、衣装持込、配慮事項、店舗へのメッセージを事前共有します。

TEL

電話・店頭予約

LINEを利用しない予約もPC・iPadから登録し、オンライン予約と同じ予定・顧客情報で扱います。

FIND

顧客・対象者検索

電話番号、氏名、顧客番号、撮影対象者名から既存顧客と過去の撮影情報を探します。

TODAY

来店予定、受付済み、準備中、撮影中、セレクト・会計案内、当日完了を現場画面で更新します。

NOTE

撮影カルテ

衣装、ヘアメイク、撮影メモ、お気に入りカット、次回への注意事項などを撮影履歴へ残します。

SELECT

写真セレクト案内

外部ギャラリーURL、案内状態、選択期限、写真選択済みまでの進捗を管理します。

SHIP

制作・納品管理

写真データ、プリント、アルバム、台紙などの制作状況、納品予定、受取・配送方法を管理します。

RE+

再注文・タスク管理

追加データ、プリント、アルバム、台紙、ご家族分などの相談と、案内・期限タスクを管理します。

FROM BOOKING TO REORDER

予約から再注文まで、
7つの流れ。

お客様がLINEから予約した時点から、写真館の当日業務、撮影後の写真選び・納品・追加注文までをつなぎます。

01

プラン・日時を予約

お客様が撮影プラン、オプション、担当者、空き時間を選びます。

02

対象者・希望を登録

撮影する方やペット、希望イメージ、希望カット、配慮事項を送信します。

03

写真館が予約確認

LINE予約と電話・店頭予約を同じ一覧で確認し、持ち物や事前案内を準備します。

04

受付・撮影進行

iPad・スタッフ画面で受付、準備、撮影中、会計案内、当日完了へ更新します。

05

撮影カルテを保存

撮影内容、対象者ごとの様子、お気に入りカット、次の対応を履歴へ残します。

06

セレクト・制作・納品

外部ギャラリーを案内し、選択期限、制作状況、納品予定、受取方法を共有します。

07

再注文を受付

追加プリント、アルバム、台紙、ご家族分などの相談を受け、対応状況を管理します。

どのような写真館・撮影メニューに向いていま⁠す⁠か⁠。

七五三、家族写真、成人式、プロフィール、証明写真、ペット、商品撮影など、複数の撮影プランを扱い、予約前の希望確認から撮影後の納品までを整理したい写真館・フォトスタジオに適しています。実際のプラン構成は導入時に調整します。

スマートフォンやiPadだけでも使えま⁠す⁠か⁠。

お客様の撮影予約・マイページはスマートフォン向けです。受付・撮影進行にはiPad画面、カメラマン・スタッフにはタブレットやPCで開ける画面を用意しています。総合管理と店舗設定はPC利用を基本とします。

LINEを利用しないお客様の予約にも対⁠応⁠で⁠き⁠ま⁠す⁠か⁠。

はい。電話・店頭予約を写真館PCまたは受付iPadから登録し、LINE予約と同じ予約一覧・当日進行で管理できます。

現在使っている写真ギャラリーや会計と併用で⁠き⁠ま⁠す⁠か⁠。

併用を前提にできます。本システムは外部ギャラリーURLとセレクト・制作・納品の進捗を管理し、写真データ保管や決済そのものは置き換えません。個別の自動連携は別途確認します。

公開デモに本物のお客様情報や写真は入っていま⁠す⁠か⁠。

入りません。公開デモは架空データを使用し、写真データそのものも保存しません。本番環境は契約スタジオごとに分離して構築します。
