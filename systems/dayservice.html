MAIN FEATURES

デイサービスの家族連絡に必要な、
10の主要機能。

介護請求ソフトではなく、日々の家族連絡、送迎案内、今日の利用者確認を使いやすくする機能へ集中しています。

ID

利用者本人確認

登録電話番号と利用者番号で確認し、ご家族に必要な予定・送迎・連絡画面を表示します。

OFF

お休み連絡

利用予定日、理由、補足を入力し、欠席連絡を施設へ送信します。

DATE

利用日変更希望

現在の利用予定日と希望日を入力し、施設確認前の変更希望として送信します。

BUS

送迎時間確認

次回利用日、送迎方法、お迎え予定、お帰り予定を家族画面へ表示します。

BAG

持ち物・お知らせ

利用者ごとの持ち物メモと、施設からのお知らせをまとめて確認できます。

CARD

利用者カード

今後の利用予定、送迎、欠席・変更希望の履歴、ご家族情報を一画面にまとめます。

TODAY

今日の状況ダッシュボード

本日の利用予定、来所済み、利用中、お休み、未対応家族連絡、今日やることを表示します。

CRM

利用者・家族検索

利用者名、家族名、電話番号、利用者番号から検索し、予定や連絡履歴を確認します。

STATUS

利用状況・送迎更新

利用予定、来所済み、利用中、帰宅準備、送迎出発、帰宅完了、お休みへ状態を更新します。

CHECK

日常確認・連絡文面

昼食、入浴、レク、家族連絡、帰宅準備の確認と、ご家族へ送る連絡文面を管理します。

DAILY COMMUNICATION FLOW

ご家族の連絡から施設対応まで、
7つの流れ。

家族連絡と当日の利用状況を分けず、一人の利用者に関する情報として連続して管理します。

01

利用者を確認

ご家族が登録電話番号と利用者番号で本人確認します。

02

用件を選択

欠席、利用日変更、送迎、持ち物、施設への連絡から選びます。

03

施設へ送信

連絡内容を送信し、施設管理PCの家族連絡一覧へ反映します。

04

施設が確認

未確認、確認済み、対応中、対応済みなどの状態で管理します。

05

利用予定・送迎を更新

電話・窓口受付を含め、利用予定と送迎時間を登録します。

06

当日の状況を更新

来所、利用中、帰宅準備、送迎出発、帰宅完了へ更新します。

07

家族が再確認

利用者カードで今後の予定、送迎、連絡履歴、お知らせを確認します。

BEFORE / AFTER

電話や紙をなくすのではなく、
確認しやすい連絡経路を増やす。

緊急連絡は電話のまま残し、日常的な欠席、変更希望、送迎確認、持ち物確認をLINEへ分けます。

BEFORE

朝の電話と紙のメモへ連絡が集中。

  • 欠席電話が重なる
  • 送迎時間の問い合わせが多い
  • 家族連絡の対応状況が分かれやすい
  • 現場状況が担当者ごとに分かれる
→
AFTER

日常連絡をLINEと同じ利用者情報へ整理。

  • 欠席・変更希望を家族が送信
  • 送迎・持ち物を家族が自分で確認
  • 未対応連絡を管理PCへ集約
  • スタッフがiPadで利用状況を更新

医療・正式記録の代替ではない

介護請求ソフトではない

介護保険請求、加算管理、ケアプラン管理は対象外とし、既存の介護ソフトと役割を分けます。

FAQ

よくある質問。

LINEを使わないご家族への対応はできますか。

施設管理PCから電話受付・窓口受付として利用予定や連絡内容を登録し、同じ利用者情報で管理できます。

送迎時間はご家族が確認できますか。

はい。利用者確認後に、次回利用日、送迎方法、お迎え予定、お帰り予定を表示できます。

スタッフはスマートフォンやiPadで操作できますか。

はい。iPad向け画面から、利用状況と昼食・入浴・レク・帰宅準備などを大きなボタンで更新できます。

介護記録や介護請求に使えますか。

いいえ。本システムは家族連絡、送迎案内、今日の利用状況確認を補助するものです。正式な介護記録や介護請求ソフトの代替ではありません。

電話番号の表記が違っても検索できますか。

はい。ハイフン、空白、全角、国番号などの表記を整え、同じ電話番号を探しやすくします。
