CONNECTED OPERATION

DPROと外部サービスを、
安全につなぐ。

DPRO CONNECTは、DPROシステムとGoogleカレンダーやSquareなどの外部サービスを、利用者自身の承認に基づいて連携するための接続基盤です。

Google Calendar Square OAuth 2.0 暗号化された認証情報

Googleカレンダー連携

DPROで登録・変更・取消した予約情報を、接続したGoogleカレンダーへ作成・更新・削除します。

Square連携

DPROからSquareの安全な決済ページを発行し、事前決済の運用を支援します。カード番号をDPROへ保存しません。

利用者が接続を承認

外部サービスへの接続はOAuth等の正式な認可画面を通じて、利用者自身が許可した場合にのみ有効になります。

Googleユーザーデータの取扱い

DPRO CONNECTがGoogle APIから取得・利用するデータは、Googleカレンダー連携機能を提供するために必要な範囲に限定します。

アクセス・利用Googleカレンダーの予定を表示・編集できる権限を利用し、DPRO予約に対応する予定の作成、変更、取消を行います。広告配信、ユーザープロファイリング、AIモデル学習の目的には利用しません。
保存OAuthアクセストークン・更新トークンはサーバー側の暗号化された秘密情報ストアで管理します。同期管理のため、Google側の予定ID、同期状態、同期日時等を保存する場合があります。
共有Googleユーザーデータを販売しません。連携機能の提供に必要なクラウド基盤・委託先を除き、本人の同意なく第三者へ提供しません。
取消・削除利用者はGoogleアカウントの接続管理からアクセスを取り消せます。DPRO側に保存された連携情報の削除はDPRO SHOP窓口へご依頼いただけます。

DPRO CONNECTによるGoogle APIから取得した情報の使用は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

プライバシーポリシー サービス利用上の注意事項

連携の流れ

  1. DPRO管理画面で利用したい外部連携を選択します。
  2. GoogleやSquareの正式な認可画面で、接続するアカウントと権限を確認します。
  3. 利用者が許可した後、DPRO側へ接続状態が保存され、必要な機能だけが有効になります。
  4. 許可は外部サービス側から取り消すことができます。

Googleカレンダー連携では、現在DPROからGoogleカレンダーへ予約情報を同期する運用を標準としています。
